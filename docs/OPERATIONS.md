# 批次操作

1. 用带异常样例做阶段预览，查看列数、必填值和冲突记录。
2. 执行批次后，在业务阶段定位异常分组并核对原始记录键。
3. 修复来源文件，重新上传并执行。历史批次保留供复核。
4. 对账无差异且无坏行时可提交签发。系统还会合并同一统计期、同一底数的已签发表复核跨批反推：需要追加遮蔽时按结论签发，全部可舍数字遮蔽后仍可唯一反推时本批自动暂缓；旧公报继续有效。对仍有差异的版本也可直接填写暂缓意见。
5. 签发响应回执中断时，用原请求重试即可；不会新增公报或改变已公开数字。
6. 导出复核证据并保存于交接记录。

单文件 256 KiB，最多 2000 条逻辑记录。容器重启后保留批次。恢复时使用原 Docker Compose 数据卷。
