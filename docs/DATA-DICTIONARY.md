# 字段与业务定义

输入编码 UTF-8，允许 BOM。首行必须匹配样例列顺序。记录键和业务组保留原始字符串。`kind` 允许 cell, release。说明列 `note` 可以跨行，限制 200 字。

业务字段按 `district`、`category`、`count`、`threshold`、`expected_hidden` 排列。最终值单位见阶段结果。数字接受非负整数、全角数字和完整千分位。空串、短横线、N/A、NULL 与未知为缺值。无关字段用 0 占位。

同一张表的行列合计同时公开。小于阈值的单元格做初次遮蔽，并按计数和位置追加遮蔽。将遮蔽单元格看作行节点到列节点的边，只要某条遮蔽边是桥，值就能从行列合计反推。此检查针对线性等式，对外部先验和整数区间仍需另行复核。样例证据使用虚构数据。

`incoming.csv` 包含四个业务组，第二组提供不同边界，第三组触发业务拒收，第四组需要核对。另含重复表头、冲突记录、重复回放与错误列数。`ready.csv` 含可以签发的两个组。
